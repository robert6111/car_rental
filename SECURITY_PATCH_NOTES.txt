CAR RENTAL SECURITY PATCH NOTES

This secured copy keeps the original business workflows and UI, but adds a central security layer.

Main security file:
- backend/includes/security.php

Security added:
- Secure session cookie settings: HttpOnly, SameSite=Lax, Secure when HTTPS is used
- Session strict mode
- Idle timeout: CAR_RENTAL_IDLE_TIMEOUT = 1800 seconds in backend/includes/security.php
- Session timeout redirects to login.php?timeout=1
- Login attempt throttling: 5 failed attempts then 15-minute lock
- Password reset and change-password rate limiting
- CSRF protection for POST forms through automatic token injection
- GET action token protection for existing action links that change data
- Server-side role/direct URL protection for admin-only and management pages
- Backup page admin-only, backup creation rate limit, download token, download rate limit
- Security headers: X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy
- .htaccess protection for database, backup, and internal include files without blocking CSS/JS/images

Important values to change:
- Idle timeout: backend/includes/security.php -> CAR_RENTAL_IDLE_TIMEOUT
- Login max attempts: CAR_RENTAL_LOGIN_MAX_ATTEMPTS
- Login lock time: CAR_RENTAL_LOGIN_LOCK_SECONDS
