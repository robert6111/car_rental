CAR RENTAL CUSTOMER INSTALLATION

1. Copy the full car_rental-development folder into XAMPP htdocs.
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin.
4. Import backend/database/database.sql.
5. Open: http://localhost/car_rental-development/backend/authentication/login.php
6. Login with:
   Email: setup@carrental.local
   Password: SetupAdmin@2026!
7. Go to Manage Users > Add User and create the real admin account.
8. Logout, login with the real admin, then disable/delete the setup account.
